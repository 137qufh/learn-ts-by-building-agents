# 第 0 章：搭好环境，跑通第一个 `.ts` 文件

> 这一章不讲类型语法，只解决一件事：让你在接下来的几十个小时里，写 TypeScript 的每一步都顺手。

很多人学 TS 卡住的第一步不是类型，而是"我的代码到底是怎么跑起来的？为什么编辑器报错了，程序却照样能运行？"。把这件事想清楚，后面所有章节都会轻松很多。

## 学完你能

- 用 pnpm 安装依赖，运行本仓库的示例、练习和测试
- 说清楚 `tsc`、`tsx`、`node 文件.ts` 三者的区别，知道什么时候用哪个
- 读懂本仓库 `tsconfig.json` 里的每一项，并知道它们为什么这样设
- 在 VS Code 里给 TS 代码和测试打断点调试
- 用"测试驱动"的方式完成练习：看测试 → 写代码 → 变绿

## 前置知识

- 会用命令行（`cd`、运行命令）
- 会至少一门编程语言。不需要会 JavaScript，用到的 JS 知识会顺手讲

## 章末项目：Echo Agent

一个只会"复读"和处理几条斜杠命令的命令行聊天程序。它几乎没有智能，但结构和真正的 agent 一模一样：**读取输入 → 决定怎么回应 → 输出 → 继续等待**。第 6 章我们会把中间那一步换成真正的大模型调用。
